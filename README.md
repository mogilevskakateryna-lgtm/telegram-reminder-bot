# Бот-нагадувалка в Telegram

Особистий бот, який нагадує про задачі й платежі та не відстає, доки ви їх не зробите. Задачі пишуться звичайним текстом («щомісяця 10-го оплатити оренду»), а Claude перетворює їх на нагадування з датою і повтором.

**👉 Покрокова інструкція без програмування: https://mogilevskakateryna-lgtm.github.io/telegram-reminder-bot/**

## Що вміє

- нагадує вчасно і повторює, доки не натиснете «Зроблено»;
- кнопки «+1 година», «Увечері», «Завтра», «Пропустити раз»;
- ранковий план, вечірній список незробленого, підсумки тижня в неділю;
- регулярні задачі: щодня, щотижня, щомісяця.

## Налаштування (змінні середовища)

| Змінна | Обовʼязкова | Що означає |
|---|---|---|
| `TELEGRAM_TOKEN` | так | токен від @BotFather |
| `ANTHROPIC_API_KEY` | так | ключ з console.anthropic.com |
| `DB_PATH` | так, на Railway | `/data/tasks.db` (разом із Volume `/data`) |
| `TZ_NAME` | ні | часовий пояс, за замовчуванням `Europe/Warsaw` |
| `REPEAT_HOURS` | ні | повтор нагадування, годин (2) |
| `QUIET_FROM` / `QUIET_TO` | ні | нічна тиша для повторів (22 / 8) |
| `MORNING_HOUR` / `EVENING_HOUR` | ні | ранкове й вечірнє зведення (8 / 21) |
| `WEEKLY_HOUR` | ні | підсумки тижня в неділю (20) |
| `OWNER_ID` | ні | ваш Telegram ID, якщо треба закріпити власника |
